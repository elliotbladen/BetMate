# EPL cards Step 2 — leak-free feature table

Generated by `build_epl_cards_features_step2.py` from
`epl_card_results_2022_23_to_2025_26.csv`.

The output has 1,520 rows and creates features before each match. The first
2022/23 features are seeded only from EPL matches before 1 August 2022. For each
match date, all features are calculated first and the day's results are added to the
history only afterwards. This prevents a result from one fixture leaking into another
fixture on the same date.

The feature groups are:

- `league_*_prior`: recency-weighted league yellow-card and foul baselines.
- `ref_*_prior` and `ref_games_prior`: referee yellow-card and foul tendency with
  empirical-Bayes shrinkage toward the league baseline.
- `*_team_yellow_mean_prior`: team cards received, with home/away splits.
- `*_cards_drawn_mean_prior`: opponent cards in that team's matches.
- `*_fouls_mean_prior`: team foul rates.
- `*_games_prior`: sample sizes used by the shrinkage and thin-sample guardrails.

All feature columns are pre-match. The outcome columns (`HY`, `AY`, `HR`, `AR`,
`total_yellow_cards`, `total_red_cards`) remain in the file for training and audit but
must never be included in the predictor matrix.

Audit result: 16 matches have a referee with no prior EPL sample in the seeded
history; 3 team cold starts remain. Those rows fall back to the league prior and will
be marked as thin evidence in Step 3 rather than treated as a strong signal.
