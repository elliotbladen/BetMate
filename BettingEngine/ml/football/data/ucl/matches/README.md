# UCL historical odds review file

`ucl_historical_odds_kaggle_2003_2024.csv` is a public Kaggle dataset downloaded
on 15 September 2026. It contains 7,596 Champions League rows from 2003–2024
inside a broader 33,650-match file.

The file has static 1X2 odds (`Cote 1`, `Cote X`, `Cote 2`). It does not contain
opening odds, closing odds, bookmaker names or quote timestamps. Keep it as a
provisional benchmark only; it must not be used for opening-to-closing CLV.

Football-Data publishes EPL and EFL domestic files but no Champions League
competition file. Footiqo advertises UCL opening and closing odds, but its
public page requires an interactive export and does not expose a verified raw
download endpoint here. A paid or authenticated source should be assessed
separately before replacing this benchmark.
