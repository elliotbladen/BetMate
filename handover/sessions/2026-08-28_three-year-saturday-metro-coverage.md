# Three-year Saturday metro coverage handover

Date: 2026-08-28

Audited the requested 2023-08-28 to 2026-08-28 Sydney and Melbourne Saturday
metropolitan population against the authorised public meeting calendars.

Both jurisdictions are complete: 137/137 Sydney meetings and 137/137 Melbourne
meetings, zero missing and zero extra canonical meetings. The database contains
2,679 races and 36,186 runner records across the 274 meetings. No network import
was needed because the existing canonical data exactly matched discovery.

The latest completed Saturday is 2026-08-22. Provincial standalone Saturdays
are intentionally outside this city-metro population. See
`RacingEngine/reports/data/saturday_metro_3y_coverage_2026-08-28.md` for field
completeness caveats relevant to later backtesting.
