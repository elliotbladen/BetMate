# Handover — handicap rematch calibration

Built `handicap-weight-rematch-v1` using first subsequent WFA/set-weight
rematches within 365 days. Named horses were excluded from fitting. On 860
pre-2025 pairs, 25% weight response beats zero and full; it repeats on 649
validation pairs. Group 1 selects 15% and Group 1 miles zero, so there is no
broad support for a universal 50% rule.

The Sheza Alibi/Gringotts Doncaster-to-22-August-WFA rematch independently
implies 55.91% for that race, revising Gringotts to about 109.62 relative to
Sheza's 113.49. The correct design is 25% initial generic treatment plus a
separate later collateral revision. Do not leak the August result into earlier
predictions or set the global coefficient from the named pair.
